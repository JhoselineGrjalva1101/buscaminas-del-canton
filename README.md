## 1. Nombre y frase

**Buscaminas del Cantón**

> Es el buscaminas de toda la vida, pero las minas son zonas de riesgo de un cantón (como deslaves o inundaciones), y al final te cuenta qué significaba cada una.

## 2. Qué hace y cómo se usa

Destapá las zonas seguras del mapa evitando las zonas de riesgo.
Usá la bandera para marcar una zona sospechosa; podés jugar con toques o con el teclado.
Al ganar o perder se revela el mapa y aparece el significado de los riesgos.

## 3. Enlace para abrirlo

[Abrir Buscaminas del Cantón](http://localhost:5173/) (con el servidor local iniciado).

## 4. Cómo correrlo en otra máquina

Con Node.js y npm instalados, desde la carpeta del proyecto:

```bash
npm install
npm run dev
```

Abrí la dirección que muestre Vite en la terminal (por defecto, `http://localhost:5173/`).

Para ejecutar las pruebas:

```bash
npm test
```
